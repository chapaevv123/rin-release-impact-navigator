RIN is an evidence-backed Python release-impact investigator and static replay UI. This local candidate is prepared for owner review; no public release or deployment has occurred.

- Approved dark-neon investigation console with six working routes, accessible evidence controls and mobile layout.
- Real Starlette 0.36.3 / HTTPX 0.27.2 → 0.28.0 case: six receipts, a recorded PASS→TypeError constructor comparison and bounded `REVIEW`.
